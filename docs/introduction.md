# Introduction

Ce projet est une plateforme de type "Airbnb-clone" développée avec le framework PHP **Laravel**. Elle permet aux utilisateurs de mettre en location des appartements et de consulter les offres disponibles.

## Aperçu du projet

L'application offre une interface moderne et responsive pour gérer les annonces immobilières. Les utilisateurs peuvent s'inscrire, se connecter, ajouter des appartements avec des photos, et filtrer les annonces selon différents critères.

## Stack Technique

- **Framework PHP :** Laravel 13.x
- **Frontend :** Blade Templates, Vanilla CSS, Vite
- **Base de données :** SQLite (par défaut pour le développement) ou MySQL
- **Gestion des assets :** NPM & Vite
- **Validation :** Form Requests Laravel
- **Authentification :** Système natif de Laravel
