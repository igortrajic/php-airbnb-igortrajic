# Documentation du Projet PHP-Airbnb

Bienvenue dans la documentation technique du projet PHP-Airbnb. Ce projet est une application web de mise en relation pour la location d'appartements.

## Sommaire

1.  [**Introduction**](introduction.md) : Présentation générale et stack technique.
2.  [**Installation**](installation.md) : Guide pour configurer l'environnement local.
3.  [**Modèles de Données**](modeles-donnees.md) : Explication de la structure de la base de données et des relations Eloquent.
4.  [**Fonctionnalités**](fonctionnalites.md) : Détail des capacités offertes par l'application.
5.  [**Routes**](routes.md) : Liste des points d'entrée (endpoints) et leurs rôles.
